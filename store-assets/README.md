# Store Assets

Run `npm run assets` to regenerate the icon and promo PNG files from
`assets/gitreview-icon.svg` and the listing compositions in
`scripts/generate-assets.mjs`.

- `icon-128.png`: required Chrome Web Store icon
- `promo-440x280.png`: required small promotional tile
- `screenshot-review-queue-1280x800.png`: real product screenshot captured in Chrome
